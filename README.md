# NEXUS HR // Enterprise Workforce & Human Capital Management System

An enterprise HR and workforce management system built with React, Vite, Tailwind CSS, and Zustand, modeled on a Supabase/PostgreSQL relational employee and payroll schema.

## 💼 Core Capabilities
- **Structured Employee Directory**: Table-first layout with department filtering, location tagging, and direct reporting lines.
- **Biometric & Shift Attendance Tracker**: Clock-in/out console with punctuality signal and shift history logs.
- **Leave Request & Manager Workflow**: Balance counters (Vacation, Sick, Personal) with dual-action approval/rejection queues.
- **Interactive Payslip Generation**: Itemized gross pay, tax deductions, 401(k), and healthcare withholding with printable PDF export.
- **Hierarchical Org-Chart**: Visual tree mapping executive nodes and departmental reporting hierarchies.
- **Performance Calibration**: Quarterly OKR tracking, reviewer remarks, and milestone completion bars.

## 🚀 Quickstart
```bash
npm install
npm run dev
```
